# ديوان | المكتب التنفيذي

نموذج تفاعلي عربي يجمع الجدولة، وتحضير الاجتماع، ومتابعة التوجيهات، ومساحات المجالس واللجان. [فتح ديوان](https://salahassi.github.io/diwan-executive-office/)

## تجربة تحليل محضر

افتح [مركز الذكاء الاصطناعي](https://salahassi.github.io/diwan-executive-office/#ai)، والصق نص محضر أو اقرأ ملفًا نصيًا أو عرض PowerPoint. يعرض المركز القرارات والتكليفات والمخاطر مع الشاهد من النص، ويتيح مراجعة أي تكليف وتحويله إلى توجيه. يمكن كذلك مقارنة قيمة مؤشر في مصدرين والبحث عن محاضر وتوجيهات سابقة ذات صلة.

## كيف تعمل المزايا

- **تحليل المحاضر:** مصنّف إحصائي محلي مدرّب على عبارات عربية توضيحية. يستخدم خصائص الكلمات والمقاطع الحرفية، ويختار للموجز عبارات من المصدر. يستخرج أسماء الجهات والمواعيد الصريحة وفق أنماط لغوية، ويحيل المخرجات للمراجعة قبل إصدار التوجيه. قد يفوّت تكليفًا أو قرارًا غير واضح الصياغة.
- **مقارنة الأرقام:** يطابق المؤشرات والوحدات والنطاقات التي يتعرّف عليها، ويعرض الفرق والاقتباس من كل مصدر. يمكن تجربة النسب المئوية والأرقام العربية والغربية.
- **استرجاع السوابق:** يبحث في سجلات المكتب ويرتّب النتائج باستخدام BM25 وتطبيع الكلمات ومجموعة مرادفات عربية. يفتح كل اقتباس السجل الذي ورد فيه.

## تشغيل النسخة وتدريب المصنّف

للتشغيل محليًا استخدم الأمر التالي من جذر المستودع وافتح `http://localhost:8000/` في المتصفح.

```sh
python3 -m http.server 8000
```

يتضمن [سكربت التدريب](tooling/train_ai.py) أمثلة التدريب والتقييم، ويعيد إنشاء `ai-model.js` عند تشغيل `python3 tooling/train_ai.py`.

يقرأ التطبيق الملفات ويشغّل المصنّف داخل المتصفح، ويحفظ سجلات المكتب في التخزين المحلي. بيانات البداية توضيحية. ينشر GitHub Pages الملفات من جذر فرع `main`. ترخيص الخطوط مرفق في [FONT-LICENSE.txt](FONT-LICENSE.txt).
