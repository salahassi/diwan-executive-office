# ديوان | المكتب التنفيذي

نموذج تفاعلي باللغة العربية يجمع جدول معالي الوزير، وتحضير الاجتماعات، ومتابعة التوجيهات، ومساحات المجالس واللجان. يتضمن واجهة مناسبة للجوال وبيانات توضيحية لتجربة دورة الاجتماع كاملة.

يمكن بدء التجربة من «تباين في بيانات العرض» في لوحة المكتب التنفيذي، ثم فتح «المحضر والتوجيهات» في اجتماع متابعة مشاريع الإسكان التنموي، واستخراج توجيه وإسناده إلى الجهة المسؤولة.

## التشغيل المحلي

شغّل الأمر التالي من جذر المستودع، ثم افتح `http://localhost:8000/` في المتصفح.

```sh
python3 -m http.server 8000
```

## البيانات والنشر

يقرأ المتصفح الملفات المرفقة محليًا ويحتفظ بالتغييرات في التخزين المحلي. يستخدم النموذج قواعد تجريبية لتحليل المحتوى واستخراج التوجيهات. ينشر GitHub Pages ملفات الموقع من جذر فرع `main`.
